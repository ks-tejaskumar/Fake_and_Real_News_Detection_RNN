# Fake and Real News Detection using RNN

## Project Overview
This project implements a Recurrent Neural Network (RNN) model to detect fake and real news articles. The model is trained on a dataset containing labeled news articles and aims to classify news as either fake or real based on the text content.

## Features
- Preprocessing of news text data
- Implementation of RNN for text classification
- Training and evaluation of the model
- Prediction on new/unseen news articles
